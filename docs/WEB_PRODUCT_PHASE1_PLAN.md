# DEMO 私有试用阶段产品计划

> 文档版本：`v1.0`
> 日期：2026-09-16
> 状态：当前

## 1. 阶段目标

让管理员 Cleo 与最多两名受邀教师通过 `https://td.unreached.top` 完成真实工作闭环，重点发现稳定性、交互和识别质量问题，不以扩张用户数或高并发为目标。

核心闭环：

1. 邀请注册与登录；
2. 每位教师进入独立工作区；
3. 管理班级、学生、座位、课表和日程；
4. 上传资料或作业，查看原文、OCR 和 AI 建议；
5. 教师复核并确认正式结果；
6. 系统保留原始证据、处理状态和可纠正入口。

## 2. 当前产品与控制边界

- OCR 和 AI 只产生可追溯草稿或建议，不能绕过教师确认静默写入正式知识结构或评分结果。
- 局部页面、资料或任务失败应隔离，不阻塞其他已完成内容。
- 上传上限为 80 MiB；文件通过受保护接口访问，不暴露静态上传目录。
- 用户、角色和每教师工作区必须隔离；未登录请求不得读取业务数据。
- 桌面与手机是同一响应式产品，不建立两套应用。

## 3. 当前基础设施决策

- 生产入口：`td.unreached.top`。
- 生产区域：腾讯云硅谷二区；Node 回环监听，Nginx + HTTPS 对外。
- 权威生产数据：服务器 `/var/lib/teacher-dashboard/product-<time>`；迁移前本地 `var-product` 保留为短期回滚源。
- 上海实例不运行 DEMO，后续独立用于 Hermes。
- 当前不购买 COS、CDN 或收费 SSL；两个用户和约 506 MiB 迁移快照不足以证明这些成本必要。
- 海外链路的中国内地访问体验必须通过真实运营商和手机网络验证，不能从 30 Mbps 峰值带宽推导稳定体验。

部署、恢复和回滚见 [OVERSEAS_PRODUCTION_DEPLOYMENT.md](./OVERSEAS_PRODUCTION_DEPLOYMENT.md)、[WEB_OPERATIONS_RUNBOOK.md](./WEB_OPERATIONS_RUNBOOK.md) 与 [WEB_DATA_MIGRATION_RUNBOOK.md](./WEB_DATA_MIGRATION_RUNBOOK.md)。

## 4. 验收与反馈

基础上线验收：

- HTTPS 证书、HTTP 跳转、首页与静态资源；
- `live/ready`、未登录 401、登录与会话；
- 班级/课表/资料/知识结构的核心只读页面；
- 手机浏览器首屏与核心操作；
- systemd 重启恢复和一次自动备份演练。

真实试用期记录：

- 失败发生在哪个用户、页面、输入和阶段；
- 数据是否保存、任务是否可重试；
- 中国内地网络的首屏、上传和 PDF/OCR 查看体验；
- AI/OCR 的准确性、延迟和调用成本。

只有真实反馈显示瓶颈后，才决定是否增加对象存储、CDN、机器规格或异地备份。

## 5. 暂不做

- 不承诺高并发、跨区域容灾、零停机升级或全国一致网络速度；
- 不开放自由注册或扩大公开推广；
- 不把 Hermes 与 DEMO 部署在同一实例；
- 不用旧上海服务器副本覆盖最新产品数据；
- 不把测试通过等同于真实教师验收。
