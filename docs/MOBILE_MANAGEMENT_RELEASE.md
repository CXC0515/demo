## 问题、决策与范围

手机班级详情原先在列表下方展开、座位图被辅助面板挤压、课表保留桌面最小宽度、四象限及标签分类纵向堆叠。目标是完成手机上的查看、定位和轻量编辑闭环，同时保留电脑端效率。用户于本任务批准实施，并明确授权 PR、合并和上线。

本次需要修改前端。最短路径为复用既有业务数据及保存接口，仅调整布局、入口和座位草稿变换。备选的整体缩放会压缩触控区域，因此课表采用紧凑格子和信息重排，座位图保留可读宽度及受控横向滚动。

- ClassManagement：手机卡片省略学期，详情底部上滑；中屏右侧弹层，宽屏详情栏；编辑和班委操作共享原生 dialog。
- StudentManagement / App：增加“查看学生画像”，定位对应班级和学生。
- VirtualClassroom：待安排名单按需打开；点击交换、左右循环移列、电脑指定行列交换；预览、撤销、保存失败保留草稿；保存后清除旧学生详情状态。
- ScheduleReminder：紧凑 5/7 天课表、手机 2×2 四象限、更多操作入口，清单布局保留。
- TagManagement：手机四分类同一行，完整分类名在内容标题显示。
- ResponsiveDialog：原生模态焦点、Escape、焦点恢复、安全区和下滑关闭手柄。
